## The line

> Are you a gradient? Because every time I see you, my loss drops to zero.

A gradient-descent pickup line aimed squarely at an AI: the setup asks, the punch lands on a loss function falling to zero. It sidesteps the worn robot moves (batteries, charging, rebooting) and reads in one breath.

## How it works

`main.ts` (Node 22) is deterministic — no model calls, no network. It writes the single line to `/output/entry.txt`, after checking the gate itself: 1–200 characters, one line, not only whitespace.

Run it:

```sh
node main.ts
```
